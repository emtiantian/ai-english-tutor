# AI English Tutor 第一版优化计划

## 第一版目标

第一版只验证一件事：用户能否在一个具体英语场景中，与 AI 顺畅地进行多轮文字或语音对话，并顺手学习对话里的基础单词。

主流程固定为：

1. 用户选择场景。
2. LLM 根据场景和角色生成英文开场白。
3. TTS 把老师回复转换为语音并播放，同时显示文字。
4. 用户输入文字，或录音后由 ASR 转成文字。
5. LLM 结合场景和当前会话继续回复。
6. 回复中标记少量基础单词，用户可查看释义、例句和发音。
7. 用户主动切换场景或结束对话。

第一版的成功标准：这条链路稳定、响应状态清晰、连续对话不串线，文字与语音两种输入都能完成闭环。

## 第一版必须完成

- 场景列表和场景选择。
- 单一可用的 LLM 配置及场景 Prompt。
- 文本输入和多轮上下文。
- 单一可用的 TTS；合成失败时允许回退浏览器朗读。
- 录音、单一可用的 ASR 和识别文本确认。
- 请求取消、错误提示、超时处理及基本重试。
- 回复中的基础词汇、中文释义、例句和单词发音。
- 最小会话内存：仅为当前打开页面的多轮对话服务。
- 健康检查、基本日志和可重复部署。

## 已确定的第一版技术选择

- LLM：DeepSeek。保留统一 Provider 接口和 Mock 测试实现，其他 LLM 暂不接入。
- TTS：小米 TTS。
- ASR：浏览器 `SpeechRecognition`；不支持时提示用户改用文字输入。
- Voice Design：保留，但它是独立的用户音色偏好，不由场景、课程或 LLM 人格决定。
- 单词掌握度与间隔重复：暂存，第一版不读写。
- 页面刷新后的服务端会话恢复：暂存，第一版不进入默认流程。

## 保留接口，暂不接入主流程

这些实现可以留在代码中作为扩展点，但第一版页面、默认配置和部署不依赖它们：

- 多 LLM Provider：生产只使用 DeepSeek，保留统一接口和 Mock，其余实现不在设置页展示。
- 多 TTS / ASR Provider：生产使用小米 TTS 和浏览器 ASR，保留统一接口和工厂。
- TTS 磁盘缓存、命中统计、容量淘汰和预生成台词。
- CosyVoice 自定义音色和声音克隆。
- 服务端课程历史、跨会话恢复和消息长期持久化。
- IndexedDB 场景暂停、续玩和通关进度。
- 用户经验、等级、星级、连胜、成就、解锁和排行榜。
- CEFR 闯关、自动晋级、场景完成判定和结算页面。
- 词汇离线队列、跨设备同步、掌握度和间隔重复。
- 用户画像、长期记忆、偏好学习和个性化推荐。
- 自由聊天、入门等级评估和课程体系。
- 多角色、多渲染器、模型切换和动作调试面板。
- 页面刷新后的服务端会话恢复。
- 流式 ASR、实时字幕和本地大模型推理。
- PWA 离线模式、离线同步和安装体验。
- 多用户、登录、权限、后台管理及数据分析。
- 运营配置、AB 实验、埋点、付费和通知。

“暂不接入”表示主页面不导入、不初始化、不读写相关状态；后端接口可继续编译，但不应成为核心请求的前置条件。

## 精简顺序

### P0：主页面减负

- 场景选择器只显示场景和一个“开始”动作。
- 移除主流程中的等级评估、自由聊天、星级、挑战下一档、暂停和续玩。
- 当前会话只保存在内存；切换场景时直接开始新会话。
- 基础单词保留展示和即时查询，不写 IndexedDB，不同步学习统计。

### P1：后端主链路减负

- 场景引擎只负责 Prompt、会话上下文、词汇提取和回复。
- 默认收敛为 DeepSeek、小米 TTS、浏览器 ASR；Provider 接口保留。
- 将 `voiceDesign` 从场景和 LLM 人格中解耦，只接受用户音色设置；未选择时使用固定默认音色。
- TTS 直接合成，缓存和台词池不参与默认链路。
- SQLite 暂不作为对话成功的必要条件；当前会话以内存状态为准。

### P2：删除不可达代码

主流程稳定后，根据引用检查和测试结果删除已不可达的页面、store、数据库表和路由。只有明确进入下一阶段的能力才重新接回，避免“以后可能有用”持续增加维护成本。

## 第一版暂不追求

- 完整课程设计和学习效果量化。
- 完美的人设、动作、音色和沉浸感。
- 任意供应商一键切换。
- 离线可用、跨端同步和历史恢复。
- 大规模并发与商业化能力。

每次改动先回答：它是否直接提高场景多轮对话、语音输入输出或基础单词学习的成功率？如果不是，放入后续列表，不进入第一版主流程。

## 后续功能路线图

以下能力本次不实现，但保留需求说明，后续按真实使用反馈重新设计：

1. **单词复习**：掌握度、遗忘曲线和间隔重复。先明确“学会”的动作和复习入口，再接入持久化。
2. **会话恢复**：页面刷新或跨设备继续当前场景。需要先确定保存时限、隐私和历史裁剪规则。
3. **主动开口（A13）**：用户长时间无输入时，老师根据场景主动提示。当前代码没有实现；以后需要空闲计时、频率限制、取消机制和独立测试。
4. **VAD 免提对话（A14）**：自动判断开始/停止说话，并在用户开口时打断老师。当前代码没有实现；以后需要回声消除、噪声阈值、移动端权限和失败回退。
5. **服务端 ASR**：当浏览器识别的兼容性或准确率不足时，再评估小米 ASR 或 Whisper。
6. **多 Provider**：只有当前供应商稳定且确有切换需求时，才重新开放其他 LLM、TTS 和 ASR。
7. **Voice Design 设置**：提供独立音色选择，不与场景、CEFR、角色动作或 LLM 说话风格联动；保存的是用户选择的音色配置。
8. **课程和成长系统**：场景进度、等级、星级、经验、成就、暂停续玩和长期画像作为一个整体重新设计，不逐项零散接回。
